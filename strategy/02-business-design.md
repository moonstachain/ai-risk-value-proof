# 02｜B轴：商业设计与成交路径

## 0. 商业裁决

客户不先买“AI 很先进”，客户先买：

```text
少出问题、少无效盯守、少解释成本、说得清投入价值。
```

所以对外不要先讲大系统，先讲：

```text
风险减量账本
```

---

## 1. 品类定义

### 对外品类名

```text
风险减量账本
```

### 方法论名

```text
风险点本体化治理
```

### 长期系统名

```text
安全价值证明系统
```

三者关系：

```text
风险点本体化治理 = 底层方法
风险减量账本 = 客户第一眼能听懂的产品入口
安全价值证明系统 = 年度平台与长期能力
```

---

## 2. 客户第一购买动机

| 客户原话 | 背后任务 | 产品翻译 |
|---|---|---|
| 风险点到底清不清 | 底数可见 | 风险点本体台账 |
| 设备到底在线不在线 | 触发可信 | 设备/信号源清单 |
| 预警后谁处理 | 责任闭环 | 五动作闭环台账 |
| 投入后有没有价值 | 向上汇报 | 风险减量账本 |

---

## 3. 产品梯度

### 3.1 免费/轻入口：风险减量诊断会

目标：让客户意识到“不是缺系统，而是风险点闭环与价值证明缺口”。

交付：

```text
风险点成熟度雷达
现有系统盘点
一个试点场景建议
90天验证边界
```

### 3.2 第一成交产品：90天风险减量验证包

目标：用一个高价值场景证明闭环能跑、价值能算。

交付：

```text
风险点本体台账
四要素建模卡
设备/信号源接入清单
闭环记录台账
风险减量账本
一号位汇报材料
```

### 3.3 年度产品：风险减量账本年度服务

目标：把一个场景扩展为多场景年度治理资产。

交付：

```text
多场景本体库
规则复用库
智能体调用台账
月度/季度价值账本
年度复制路线图
```

### 3.4 平台产品：安全价值证明系统

目标：在年度服务基础上形成平台化能力。

交付：

```text
风险点本体平台
智能体能力包
场景规则库
客户驾驶舱
数据与流程接口
```

---

## 4. 销售顺序

```text
第一步：先承认客户已有系统资产，不否定过去投入。
第二步：指出关键缺口不是系统数量，而是风险点闭环和价值证明。
第三步：用一个场景说明从一号位到设备级的下钻路径。
第四步：提出90天验证，不要求客户一开始全域投入。
第五步：用风险减量账本作为汇报成果。
```

现场第一句话：

```text
先不谈新系统，先看您已有资产能不能证明风险真的下降。
```

---

## 5. 成交判断标准

一个客户是否适合作为第一批样板，必须同时满足：

```text
1. 有明确高价值场景。
2. 有现成台账或设备基础。
3. 有一号位或牵头部门愿意推动。
4. 能接受90天试点边界。
5. 愿意用真实闭环记录验收。
```

少于三个“是”，暂不进入重交付。
