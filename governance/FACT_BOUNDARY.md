# FACT_BOUNDARY｜事实边界与对外口径

## 0. 原则

本仓库当前包含：

```text
策略判断
客户呈现方案
HTML 页面
90天验证包
数据结构模板
```

这些内容可以用于内部讨论、客户初步沟通、方案展示和试点设计。正式对外发布或签约前，必须补齐客户授权与事实核验。

---

## 1. 三类信息

| 类型 | 说明 | 使用方式 |
|---|---|---|
| 已知素材 | 学员提供的页面、截图、口述、历史方案 | 可用于策略重构 |
| 策略推断 | 基于原力战略方法论形成的商业判断 | 可用于方案建议，但需验证 |
| 待补证据 | 客户名称、真实数据、验收结果、公开授权 | 未核验前不得当成事实宣传 |

---

## 2. 对外推荐口径

```text
本方案中的样例数据用于说明方法、页面结构和交付方式。
正式实施以客户真实台账、设备平台、检查记录和项目验收数据为准。
```

---

## 3. 不允许的表达

```text
不把示例数据说成真实在线数据。
不把未授权客户案例公开化。
不把策略推断说成已完成商业结果。
不使用未经核验的具体数值做承诺。
不承诺系统能替代客户已有责任流程。
```

---

## 4. 正式发布前需要补齐

```text
1. 客户可公开名称或脱敏名称
2. 项目正式范围
3. 试点场景说明
4. 点位/设备/信号源真实清单
5. 数据更新时间
6. 闭环记录样本
7. 客户验收口径
8. 可引用原话
9. 可公开截图
10. 对外发布授权
```

---

## 5. 页面标注规范

所有 HTML 页面、报告、销售材料中，如使用样例数据，应明确标注：

```text
示意数据 / 待接入真实台账 / 已脱敏样例 / 客户已授权
```

---

## 6. 仓库当前状态

```text
v0.1 策略与呈现版
事实级别：策略重构 + 样例页面
可用于：客户初步沟通、内部方案评审、试点设计
不可用于：正式对外宣传、承诺式销售、未经授权案例发布
```
